
# Personal Finance Management System
Created by: Matt pheaton, Priscilla Olohi Eke, Elizabeth Mueni Busy

## Project Description

A C# console application that allows users to manage income,
expenses and monthly budgets using fictional financial records.

## Technologies

- C#
- .NET
- Visual Studio
- LINQ
- System.Text.Json
- Git and GitHub

## Features

- Add, view, edit and delete transactions
- Search and filter transactions
- Calculate income, expenses and net balance
- Create category budgets
- Display budget alerts
- Group expenses by category
- Save and load data using JSON

## How to Run

1. Open the solution in Visual Studio.
2. Build the project.
3. Run the application.

Alternatively, use the terminal:

```bash
dotnet restore
dotnet build
dotnet run
```

## Sample Data

The application uses fictional financial transactions.
No real financial or banking information is required.
